# Building Riftborn Realms 

## The idea

Riftborn Realms is a 2D tile-based dungeon crawler game that I'm developing in Python using Pygame.

The aim of this project is to design a game that self-generates the map design and its contents. This way the user isn't playing a pre-defined level thus adding an air of unpredictability to the game. 

## Why I decided to develop this project?

Wanted to develop a small-scale game that does not feel repetitive to play. 

- Interested by procedural generation in other games 
- wanted to try pygame
